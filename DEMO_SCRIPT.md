# StudyMate AI — 2–3 Minute Demo Script

**Opening:** "StudyMate AI is my GenAI capstone. It combines an LLM assistant, RAG, embeddings, quiz generation, function calling and task management."

**1. Document Q&A:** Upload a small text-based PDF or DOCX, process it, ask a question answered in the document, then expand retrieved passages. Explain extraction → chunking → embeddings → retrieval → LLM answer.

**2. Quiz generation:** Enter the same topic, choose difficulty and number of questions, generate the quiz and submit answers. Explain structured JSON output.

**3. Agent tools:** In chat ask "Calculate (125 * 4) + 30." Then ask "Add a study task: revise this chapter tomorrow." Show the tool-call log and Task Planner.

**Closing:** "This project demonstrates how LLM APIs, prompt engineering, RAG, embeddings, structured outputs, tools and agents can work together."

Before recording: add API key privately, test each feature, use a small text-based document, and hide secrets or personal information.
